This is a tool that I use to quickly understand an ad tech company's business model by finding its closest comparable company within a list of familiar companies.  The Python script uses FireCrawl to scrape the websites of target companies.  The script then uses gemini-2.5-flash to write a concise description of the company's business model.  Finally, the script uses Gemini to find the best-known company match for each new, unclassified company based on the company's business description.  To use this tool, just add the domain of a new company to the last row of the .csv file and run the program.
